01 · Información

¿Qué es AssendApp?

AssendApp es una herramienta digital gratuita diseñada específicamente para ayudar a los testigos de Jehová a organizar su ministerio y servicio del campo en un solo lugar.

Está disponible tanto en versión web como para dispositivos Android y funciona como un asistente de organización personal para mantener registros, dar seguimiento a revisitas, gestionar territorios y registrar la actividad de servicio.

09 · Preguntas frecuentes

Preguntas sobre AssendApp.

¿Qué es AssendApp? +

AssendApp es una herramienta digital gratuita diseñada específicamente para ayudar a los testigos de Jehová a organizar su ministerio y servicio del campo en un solo lugar.

¿Para quién está diseñada AssendApp? +

AssendApp está diseñada para los testigos de Jehová que desean organizar y llevar un mejor seguimiento de diferentes aspectos de su ministerio y servicio del campo.

¿AssendApp es gratuita? +

Sí. AssendApp es una herramienta gratuita y está disponible sin límites de uso.

¿Está disponible para Android? +

Sí. AssendApp está disponible tanto mediante su versión web como para dispositivos Android.

¿Qué puedo registrar sobre una persona interesada? +

Puedes guardar información de contacto, historial de conversaciones, temas tratados, publicaciones bíblicas dejadas y preguntas que hayan quedado pendientes para una próxima conversación.

¿Puedo configurar recordatorios para revisitas? +

Sí. AssendApp permite configurar alertas y recordatorios para ayudarte a mantener la continuidad de las revisitas.

¿Puedo llevar un control de mis territorios? +

Sí. Puedes realizar el seguimiento de calles, bloques y zonas rurales asignadas, además de registrar notas relacionadas con las viviendas.

¿Qué puedo registrar de mi actividad de servicio? +

AssendApp permite utilizar un cronómetro para registrar el tiempo de predicación y llevar el registro de publicaciones físicas o digitales, reproducciones de videos y cursos bíblicos.

¿Cómo funciona el informe mensual? +

Los datos registrados durante el mes pueden recopilarse rápidamente para facilitar el envío del informe de actividad al secretario de la congregación.

¿Quién creó AssendApp? +

AssendApp fue creada y desarrollada de forma independiente por SΛX.

¿AssendApp continúa desarrollándose? +

Sí. El proyecto continúa evolucionando mediante mejoras, correcciones y nuevas funciones.

¿Dónde puedo solicitar ayuda? +

Puedes visitar el centro de soporte de AssendApp para consultar las opciones de ayuda disponibles.
